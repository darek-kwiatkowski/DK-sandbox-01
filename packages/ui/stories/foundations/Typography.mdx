# Typography

Two families, both system fonts with no download: `font-sans` for the interface and `font-mono` for code.
Choose a **role**, not a size.

| Token | Value | Source |
| --- | --- | --- |
| `--font-sans` | `ui-sans-serif, system-ui, sans-serif` | tokeny.md (approved 2026-11-06) |
| `--font-mono` | `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` | R01.2 |

## Rules

| Rule | Source |
| --- | --- |
| Monospace for code, file names, branches and versions; never for prose, names or prices. | R01.2 |
| Lists use `text-sm`; session messages, the written answer and the note use `text-base leading-relaxed`. | K1, R02.1 |
| Reading text is capped by `max-w-reading`. | K1, R02.1 |
| Use `tabular-nums` for prices, times and counts so digits align. | F2, approved 2026-11-06 |
| One `h1` per page; headings follow document order. | WCAG 1.3.1, 2.4.6 |
| Text resizes to 200% without loss: sizes are in `rem`. | WCAG 1.4.4 |

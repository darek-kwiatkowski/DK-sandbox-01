# E02 — Mentor offer

## Flow

An invited mentor publishes a profile and public work, sets prices inside operator-defined bounds, then publishes 25- or 50-minute slots. The operator configures price bounds and the fee; the fee unit and settlement rules are not supplied by the screen proposal. (E02-S01/S02/S03; R04, R07, R08, R14, R28, R29.)

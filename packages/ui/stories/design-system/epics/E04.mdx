# E04 — Session and note

## Flow

Mentee and mentor hold one linear text session. The mentor delivers a written answer; both people co-edit one private note, and the mentee approves its final version. (E04-S01/S02; R02.2–R02.3, R02.8, R20, R26, R31.)

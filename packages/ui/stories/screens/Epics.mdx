# Backlog screen map

E02–E05 screens are proposals because the backlog has no detailed screen specifications for them. The screen compositions use real `@devmentor/ui` exports and should be treated as design inputs pending product review. E06 is Later and has no 1.0 screen. (Design system spec decision, 2026-11-06; backlog E01–E06; product brief D34, D48.)

The fullscreen state stories use static application-state fixtures and no-op retry/note callbacks. They show layout and feedback, not working persistence or reconnect recovery. The composer simulates a successful response only. (Approved Q2/H4; E04-S01/S02 presentation boundary.)

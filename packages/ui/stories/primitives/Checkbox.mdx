# Checkbox

## 1. Purpose

Lets the user turn an option on or off, or pick several options from a short list.

## 2. When to use

| Situation in DevMentor | Source |
| --- | --- |
| A mentor's stack tags: TypeScript, React, Python, AI agents (several at once) | R13, E02-S01 |
| The stack filter on the mentor list | R13, E03-S01 |
| A single yes/no setting saved with a form | — |

## 3. When not to use

| Instead of a checkbox… | Use |
| --- | --- |
| Exactly one of a few options (25 or 50 minutes) | Radio group |
| An action that happens immediately | Button |
| A setting that applies instantly without saving | A switch would fit, but it is not in the system (What is missing); use a checkbox saved with the form |

## 4. Anatomy

| Part | Optional | Notes |
| --- | --- | --- |
| Box | no | 16 px; the hit area extends 12 px sideways and 8 px up and down |
| Check mark | when checked | lucide `Check`, `aria-hidden` |
| Label | no | `FieldLabel` to the right, clickable |
| Hint | yes | `FieldContent` with `FieldDescription` |

## 6. States

<Canvas of={CheckboxStories.States} />

| State | What changes | Source |
| --- | --- | --- |
| Unchecked | `border-input` (3 : 1) | WCAG 1.4.11 |
| Checked | Ink fill and white check, not the accent | tokeny.md rule 3 |
| Indeterminate | Supported by Radix (`checked="indeterminate"`); not used by any screen yet | — |
| Hover | Border becomes ink | — |
| Focus | Ink ring with offset | WCAG 2.4.7 |
| Disabled | 50% opacity; the label or hint says why | WCAG 3.3.2 |
| Error | `aria-invalid` red border plus a FieldError for the group | WCAG 3.3.1 |
| Pressed, loading | Do not apply | — |

## 7. Behaviour and accessibility

| Topic | Rule | Source |
| --- | --- | --- |
| Role | `role="checkbox"` with `aria-checked` (Radix) | WAI-ARIA APG Checkbox |
| Keyboard | `Tab` focuses, `Space` toggles | WAI-ARIA APG Checkbox |
| Label | Clicking the label toggles; the label is part of the target | WCAG 2.5.8 |
| Group | `FieldSet` + `FieldLegend` name the question ("Stack") | WCAG 1.3.1 |
| Screen reader | "TypeScript, checkbox, checked" | — |

## 8. Content

| Rule | Example |

## 10. API

<ArgTypes of={CheckboxStories} />

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean \| "indeterminate"` | — | Controlled state |

# Alert

## 1. Purpose

Tells the user something about the whole page or form that they must know: a rule before they pay, a result, or a problem and what to do.

## 2. When to use

| Situation in DevMentor | Role | Source |
| --- | --- | --- |
| The no-refund rule before payment | `note` (static) | R27, P17 |
| "Sesja jest tekstowa…" on session screens | `note` | R03 |
| The result after a redirect: "Połączyliśmy konto z GitHub…" | `status` | E01-S01 spec |
| A sign-in or server error from `?error=` codes | `alert` (default) | E01-S01 spec |
| A stale note with a reload action | `alert` with `AlertAction` | Platform primitives P15 |

## 3. When not to use

| Instead of an alert… | Use | Source |
| --- | --- | --- |
| An error of one field | FieldError under the field | WCAG 3.3.1 |
| Loading data failed with a retry | ErrorMessage (batch 3) | Engineering standards |
| A message that disappears by itself | Not in the system: errors that need action are never temporary | Toast omitted, Q5 |
| Promotion or urgency ("Ostatnie terminy!") | Nothing | A06, R14 |

## 4. Anatomy

| Part | Optional | Notes |
| --- | --- | --- |
| Icon | yes | lucide 20 px, `aria-hidden`; `Info` for notes, `CircleAlert` for problems |
| `AlertTitle` | yes | What happened, one line |
| `AlertDescription` | no | What to do or what it means |
| `AlertAction` | yes | Buttons below the text (not overlaid, so long labels fit) |

## 5. Variants

<Canvas of={AlertStories.Variants} />

| Variant | Choose it when |
| --- | --- |
| `default` | Rules, notes and results |
| `destructive` | Something failed or is blocked; red text plus `CircleAlert` |

## 6. States

| State | What changes |
| --- | --- |
| Shown | Appears in place; a new `alert` is announced immediately, `status` politely, `note` not at all |
| With action | The action follows its own button states |
| Hover, focus, disabled, loading, selected | Do not apply to the alert itself |

## 7. Behaviour and accessibility

| Topic | Rule | Source |
| --- | --- | --- |
| Role | Default `role="alert"`. Pass `role="status"` for results and `role="note"` for static rules, so screen readers are not interrupted | WCAG 4.1.3, WAI-ARIA |
| Meaning | Icon and text, never colour alone | WCAG 1.4.1 |
| Focus | Do not move focus to an alert, except after a failed form submit (Patterns/Form) | WCAG 3.2.2 |
| Contrast | Destructive text 5.52 : 1 light, 6.77 : 1 dark | WCAG 1.4.3 |

## 8. Content

| Rule | Example | Source |
| --- | --- | --- |
| Problem: what happened, then what to do | "Nie udało się zalogować przez GitHub. Spróbuj ponownie." | E01-S01 spec |
| Rule: state it plainly before the decision | "Po opłaceniu sesji nie zwracamy pieniędzy, także gdy anulujesz rezerwację." | R27, P17 |
| No exclamation marks, no blame | Not "Błąd!" | P17, A06 |
| Long text | Wraps; keep to two sentences | — |

## 9. Responsive

| Width | Behaviour |
| --- | --- |
| 320 px | Full width; the action wraps below the text |
| 768 and 1440 px | Capped by `max-w-reading` |

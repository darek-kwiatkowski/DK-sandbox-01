# Input

## 1. Purpose

Lets the user type one short value: a name, an e-mail address, a password, a link.

## 2. When to use

| Situation in DevMentor | Type | Source |
| --- | --- | --- |
| Sign-in and registration: "E-mail", "Hasło", "Imię i nazwisko" | `email`, `password`, `text` | E01-S01 spec |
| Mentor profile: "Link do publicznej pracy" | `url` | R04 |
| Operator: e-mail of an invited mentor | `email` | E01-S02, R07 |
| Prices and bounds in PLN | `text` with `inputMode="decimal"` (the `money` field of CrudForm) | R08, R29, platform primitives P18 |

## 3. When not to use

| Instead of an input… | Use |
| --- | --- |
| More than one line (description, message, note) | Textarea |
| One of a few known values (25 or 50 minutes) | Radio group |
| One of many known values (price bound step, time zone) | Select |
| Several stack tags | Checkboxes |

## 4. Anatomy

Always inside a Field:

| Part | Optional | Notes |
| --- | --- | --- |
| Label (`FieldLabel`) | no | Always visible; a placeholder is never the label |
| Input | no | 32 px, `border-input` |
| Hint (`FieldDescription`) | yes | Linked with `aria-describedby` |
| Error (`FieldError`) | when invalid | Replaces nothing: the hint stays |

## 7. Behaviour and accessibility

| Topic | Rule | Source |
| --- | --- | --- |
| Label | `FieldLabel htmlFor` = input `id`; clicking the label focuses the input | WCAG 1.3.1, 4.1.2 |
| Hint and error | Both in `aria-describedby`; the error is in a `role="alert"` region | WCAG 3.3.1 |
| Autofill | Set `autoComplete` (`email`, `name`, `current-password`, `new-password`) | WCAG 1.3.5 |
| Keyboard | Standard text editing; `Enter` submits the form | — |
| Screen reader | "E-mail, edit text, invalid entry, Konto z tym adresem już istnieje…" | — |
| Target size | 32 px high, full width | WCAG 2.5.8 |
| Text size | 16 px on phones (no zoom on focus), 14 px from 768 px | — |

## 8. Content

| Rule | Example | Source |
| --- | --- | --- |
| Label is a noun, Polish, no colon | "E-mail", "Hasło", "Link do publicznej pracy" | E01-S01 spec |
| Placeholder is an example, never the label | `anna@example.com`, `https://github.com/…` | WCAG 3.3.2 |
| Hint states the rule before the error | "Co najmniej 12 znaków." | E01-S01 spec |
| Optional fields say so in the label | "Dodatkowy link (opcjonalnie)" | WCAG 3.3.2 |
| Long values | Scroll inside the field; never truncate the stored value | — |

## 9. Responsive

| Width | Behaviour |
| --- | --- |
| 320 px | Full width of the form column |
| 768 px | Full width of a form capped at about 24 rem (`max-w-sm`) |
| 1440 px | Same as 768 px |

## 10. API

<ArgTypes of={InputStories} />

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | HTML input type | `"text"` | `email`, `password`, `url`, `number`… |
| `aria-invalid` | `boolean` | — | Error state; pair with FieldError |
| …`input` props | `ComponentProps<"input">` | — | `id`, `autoComplete`, `required`, `disabled`, `readOnly` |

## 11. Code

<Source language="tsx" code={`<Input id="email" type="email" autoComplete="email" />`} />

<Source language="tsx" code={`<Field data-invalid={Boolean(error) || undefined}>
  <FieldLabel htmlFor="email">E-mail</FieldLabel>
  <Input id="email" type="email" autoComplete="email" aria-invalid={Boolean(error) || undefined} aria-describedby="email-error" />
  <FieldError id="email-error">{error}</FieldError>
</Field>`} />

In forms that talk to the API use CrudForm, which wires all of this (Patterns/Form).

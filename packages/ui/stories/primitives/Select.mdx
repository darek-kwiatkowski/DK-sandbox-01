# Select

## 1. Purpose

Lets the user pick one value from a known list that is too long to show at once.

## 2. When to use

| Situation in DevMentor | Source |
| --- | --- |
| A slot's start time when a mentor publishes availability (every 30 minutes) | E02-S03, R14 |
| A time zone, where one has to be chosen | Platform primitives P16 (decided in E02-S03) |
| Operator settings with a fixed list of values | R35 |

## 3. When not to use

| Instead of a select… | Use | Why |
| --- | --- | --- |
| Up to about 5 short options (25 or 50 minutes) | Radio group | All options and prices visible at once (R08, P17) |
| Several values (stack tags) | Checkboxes | Select picks one value |
| A free value (price in PLN) | Input (CrudForm `money` field) | The value is not from a list |
| Searching among many names | Not in the system; there is no search in 1.0 (R13) | — |

## 4. Anatomy

| Part | Optional | Notes |
| --- | --- | --- |
| Label | no | `FieldLabel htmlFor` = trigger `id` |
| Trigger | no | 32 px (`default`) or 24 px (`sm`), shows the value or the placeholder, chevron icon |
| List (`SelectContent`) | no | Overlay in a portal, `shadow-overlay`, scrolls when long |
| Groups and group labels | yes | `SelectGroup`, `SelectLabel` |
| Separator | yes | `SelectSeparator` between groups |
| Check mark | — | Marks the selected item |

Sizes only: `default` for forms, `sm` inside dense list rows.

## 7. Behaviour and accessibility

| Topic | Rule | Source |
| --- | --- | --- |
| Roles | Trigger `combobox`, list `listbox`, items `option` (Radix) | WAI-ARIA APG Select-only combobox |
| Keyboard | `Enter`, `Space` or arrows open; arrows move; `Enter` chooses; `Escape` closes without change; typing a character jumps to it | WAI-ARIA APG |
| Focus | Returns to the trigger after closing | WCAG 2.4.3 |
| While open | The rest of the page is hidden from assistive technology | WAI-ARIA (modal list) |
| Target size | Trigger 24–32 px; items ≥ 28 px high | WCAG 2.5.8 |
| Theme | The list renders in a portal and still gets the theme from `<html>` | Design system rule 9 |

## 8. Content

| Rule | Example |
| --- | --- |
| Label names the value | "Godzina rozpoczęcia" |
| Placeholder is an instruction, not a value | "Wybierz godzinę" |
| Items are short, sorted in their natural order | Times in order, not alphabetically |
| Long items | Wrap in the list; the trigger shows one line (`line-clamp-1`) |
| Times and zones | 24-hour clock; zone label always shown (P16) |

## 9. Responsive

| Width | Behaviour |
| --- | --- |
| 320 px | Trigger full width (`w-full`); the list fits the viewport and scrolls |
| 768 and 1440 px | Trigger as wide as its longest value |

## 10. API

<ArgTypes of={SelectStories} />

| Component | Key props |
| --- | --- |

| `SelectTrigger` | `size?: "default" \| "sm"`, `id`, `aria-invalid`, `aria-describedby` |
| `SelectValue` | `placeholder` |
| `SelectContent` | `position?: "item-aligned" \| "popper"` (default item-aligned) |
| `SelectItem` | `value` (required), `disabled` |
| `SelectGroup`, `SelectLabel`, `SelectSeparator` | grouping |

    </SelectContent>

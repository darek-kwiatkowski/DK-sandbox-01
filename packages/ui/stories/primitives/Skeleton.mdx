# Skeleton

## 1. Purpose

Shows the shape of content that is loading, so the page does not jump when the data arrives.

## 2. When to use

| Situation in DevMentor | Source |
| --- | --- |
| The mentor list and the session list on first load | R01.1, E03-S01 |
| A mentor profile and the booking summary | E03-S02 |

## 3. When not to use

| Instead of a skeleton… | Use | Source |
| --- | --- | --- |
| A short wait after an action (saving, sending) | The button's loading state | Primitives/Button |
| Loading where the layout is unknown | LoadingMessage | Engineering standards |
| A whole page | LoadingMessage or skeletons of the first screenful only | — |

## 4. Anatomy

| Part | Optional | Notes |
| --- | --- | --- |
| Shapes | no | `bg-muted`, `rounded-sm`, sized like the real text lines and avatars |
| Container | no | `aria-busy="true"` |
| Status text | no | One visually hidden `role="status"` ("Wczytywanie mentorów…") |

## 5. Variants

None; compose shapes to match the content.

## 6. States

| State | What changes | Source |
| --- | --- | --- |
| Loading | Shapes pulse | P18 |
| Reduced motion | Shapes are static | WCAG 2.3.3 |
| Loaded | Replaced by content in the same place | — |
| Failed | Replaced by ErrorMessage | — |

## 7. Behaviour and accessibility

| Topic | Rule | Source |
| --- | --- | --- |
| Hidden shapes | Each shape is `aria-hidden` | WCAG 1.3.1 |
| Announcement | One status message for the whole region, not one per shape | WCAG 4.1.3 |
| Focus | Nothing focusable while loading | — |

<Canvas of={SkeletonStories.AnnouncedOnceNotPerShape} />

## 8. Content

No visible text. The hidden status says what is loading: "Wczytywanie mentorów…", "Wczytywanie profilu…".

## 9. Responsive

| Width | Behaviour |
| --- | --- |
| 320 px | Fewer rows (2–3) |
| 768 and 1440 px | As many rows as fit the first screen |

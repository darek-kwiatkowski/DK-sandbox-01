# Radio group

## 1. Purpose

Lets the user pick exactly one option when all options fit on screen, such as the length of a session.

## 2. When to use

| Situation in DevMentor | Source |
| --- | --- |
| Session length when booking: 25 or 50 minutes, each with its price | R01, R08, E03-S02 |
| Slot length when a mentor publishes availability | R01, E02-S03 |

## 3. When not to use

| Instead of a radio group… | Use |
| --- | --- |
| More than about 5 options, or long option names | Select |
| Several options at once | Checkboxes |
| An action | Button |

## 4. Anatomy

| Part | Optional | Notes |
| --- | --- | --- |
| Group | no | `RadioGroup`, named by a `FieldLegend` or `aria-label` |
| Item | no | 16 px circle; hit area extends around it |
| Label | no | `FieldLabel`; may carry secondary text (price) in `text-muted-foreground` |
| Hint, error | yes | For the whole group |

## 5. Variants

`orientation` vertical (default) or horizontal (side by side when options are short).

## 7. Behaviour and accessibility

| Topic | Rule | Source |
| --- | --- | --- |
| Keyboard | `Tab` enters the group on the selected item; arrow keys move and select | WAI-ARIA APG Radio Group |
| Roles | `radiogroup` with `radio` items and `aria-checked` (Radix) | WAI-ARIA |
| Label | Clicking a label selects its item | WCAG 2.5.8 |
| Screen reader | "Długość sesji, radio group; 25 minut · 180,00 zł, radio button, checked, 1 of 2" | — |

<Canvas of={RadioStories.ArrowKeys} />

## 8. Content

| Rule | Example | Source |
| --- | --- | --- |
| Option names are short and parallel | "25 minut", "50 minut" | R01 |
| The price sits with the option, before payment | "25 minut · 180,00 zł" | R08, P17 |
| Preselect only when there is a sensible default | 25 minutes preselected; no default when the price differs a lot is also acceptable | — (proposal) |

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value`, `defaultValue` | `string` | — | Selected item |
| `onValueChange` | `(value: string) => void` | — | Called on selection |

# Separator

## 1. Purpose

Separates two groups with a thin line, so dense screens stay readable without boxes and shadows.

## 2. When to use

| Situation in DevMentor | Source |
| --- | --- |
| Between sections inside one card or panel | R01.3 |
| Between inline facts in a row ("Anna Kowalska │ TypeScript, React") | R01.1, R01.3 |
| "lub" between GitHub sign-in and the e-mail form: use `FieldSeparator` (Primitives/Field) | E01-S01 spec |

## 3. When not to use

| Instead of a separator… | Use |
| --- | --- |
| Between rows of a table or list | `divide-y divide-border` on the list |
| To create space | Spacing tokens (`gap-between-groups`, `gap-section`) |
| Around every element | Nothing; lines only between groups |

## 4. Anatomy

One 1 px line in `--border`. Horizontal or vertical.

## 5. Variants

<Canvas of={SeparatorStories.Orientations} />

| Prop | Choose it when |
| --- | --- |
| `orientation="horizontal"` (default) | Between stacked groups |
| `orientation="vertical"` | Between inline items in a row |
| `decorative={false}` | Only when the separation carries meaning for screen readers (rare) |

## 6. States

None: the separator is static and not focusable.

## 7. Behaviour and accessibility

| Topic | Rule | Source |
| --- | --- | --- |
| Default | Decorative: `role="none"`, ignored by screen readers | WAI-ARIA |
| Semantic | `decorative={false}` gives `role="separator"` with orientation | WAI-ARIA separator |
| Contrast | Decorative lines have no threshold (1.21 : 1 light, 1.37 : 1 dark); never the only way to tell groups apart in a form | WCAG 1.4.11 (exempt) |

<Canvas of={SeparatorStories.DecorativeOrSemantic} />

## 8. Content

No text. Use FieldSeparator when a word sits on the line ("lub").

## 9. Responsive

| Width | Behaviour |
| --- | --- |
| 320 px | Vertical separators in a row turn into wrapping or stacking; prefer horizontal |
| 768 and 1440 px | Either |

<Canvas of={SeparatorStories.NarrowWidth} />

## 10. API

<ArgTypes of={SeparatorStories} />

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `decorative` | `boolean` | `true` |

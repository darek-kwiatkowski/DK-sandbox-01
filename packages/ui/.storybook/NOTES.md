# Technical note: DevMentor design system

- **Base.** Primitives in `src/components/ui/` come from shadcn/ui (style `radix-nova`, Radix UI through the
  `radix-ui` package, icons from `lucide-react`), added only with `npx shadcn@latest add <name>` in
  `packages/ui` (AGENTS.md) and then restyled to the DevMentor tokens. The base is not the product style:
  shape, density, typography and states follow `lekcja-06/referencje.md` and `lekcja-06/tokeny.md`.
- **Storybook.** 10.6.6 with `@storybook/react-vite`, `@storybook/addon-docs` (MDX with `remark-gfm`),
  `@storybook/addon-a11y` (`a11y.test = "error"`), `@storybook/addon-vitest` (Chromium through
  `@vitest/browser-playwright`), `msw` + `msw-storybook-addon` (CSF 3 loader) for `/api/*` responses.
- **Branding.** `manager.ts` sets the brand title and replaces the name Storybook hard-codes in the document
  title, the screen-reader heading and the settings menu. Telemetry, the onboarding checklist and what's-new
  notifications are off in `main.ts`.
- **Theme.** `theme.ts` toggles `.dark` on `<html>` from the toolbar global, for stories (decorator) and docs
  pages (globals channel), so portalled overlays get the theme. Story tests run once per theme through
  `STORYBOOK_THEME` (`npm run test:storybook`).
- **Where things live.** Stories and MDX in `packages/ui/stories/` (outside `src/`, so unit coverage is
  unaffected); docs-only blocks in `.storybook/blocks/` (not exported from the package); MSW worker in
  `.storybook/public/` (generated by `npx msw init`).
- **Chromium.** Playwright downloads it outside the repository (`npx playwright install chromium`).
